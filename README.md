# Wisdom Usiwoma | Portfolio

A scroll-driven personal portfolio. A welcome screen blows out to reveal a hero scene where the standing figure sits down to work, followed by my projects and contact details.

**Live site:** https://portfolio-xi-seven-w45rzaoafi.vercel.app/

## Highlights

- Scroll-driven welcome intro using a clip-path "blow-out" animation
- Hero scene with a standing-to-sitting crossfade and an about section, with separate layouts for desktop and mobile
- Project case-study pages generated from project data
- Contact section with a copy-email button and direct links
- Downloadable resume from the navbar

## Tech stack

- **Framework:** Next.js (App Router) and React
- **Animation:** GSAP and ScrollTrigger
- **Styling:** Tailwind CSS
- **Icons:** react-icons
- **Deployment:** Vercel

## Run locally

```bash
git clone https://github.com/Usiwoma2006/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open http://localhost:3000.
